# 目指せ優勝！ バックアップ/復元手順

## 対象データ
- `staff`
- `goal_settings`
- `checkins`
- `sales`

## バックアップ方針（簡易）
- 頻度: 1日1回（営業終了後）
- 保存先: 社内共有ドライブまたは安全なクラウドフォルダ
- 形式: CSV（テーブル単位）

## 手動バックアップ（Supabase UI）
1. Supabaseプロジェクトを開く
2. `Table Editor` を開く
3. 各テーブルを開く
4. `Export`（CSV）で保存
5. ファイル名に日付を付ける
   - 例: `sales_2026-05-01.csv`

## 復元の考え方
- 原則、運用中は直接復元しない
- まずは別環境で復元テスト
- 本番反映は営業時間外で実施

## 簡易復元手順（CSV）
1. Supabase `Table Editor` で対象テーブルを開く
2. `Insert` または `Import` からCSVを取り込み
3. `id` と日付列の整合性を確認
4. アプリで表示確認

## 重要注意
- `SUPABASE_SERVICE_ROLE_KEY` は絶対に公開しない
- `.env.local` はGitにコミットしない
- 誤入力修正は、履歴保持のためマイナス入力を基本とする

## 障害時の優先順位
1. 入室と売上入力が可能か
2. 今日の合計金額が正しいか
3. 目標設定が保持されているか
4. 過去ログが残っているか
