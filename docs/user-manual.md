# 目指せ優勝！ 社員向けマニュアル

## 1. まず最初に
- URLにアクセスして、`ログイン` 画面を開きます。
- 自分の名前を選んで `この担当者で入る` を押します。
- ログインすると当日の `入室` として記録されます。

## 2. ホーム画面でできること
- 今日の目標、売上、残り金額を確認できます。
- 自分のヒーローカードで達成率が確認できます。
- チーム全体の進捗も同時に見られます。

## 3. 売上入力
- `売上金額` に金額を入れて `売上を追加` を押します。
- 訂正したい場合はマイナス入力します。
  - 例: `100000` を `95000` に直したい場合は `-5000`
- 0円入力は不要です。ログイン（入室）で当日入力済みの扱いになります。

## 4. 退出
- 画面下の `退出` を押すとログイン画面に戻れます。
- 担当者を切り替えたいときも `退出` を使います。

## 5. よくある質問
- **Q: 売上ログが見えない**
  - A: 画面を再読み込みしてください。ログは最新20件まで表示です。
- **Q: 入力ロック中と表示される**
  - A: 前営業日に未入室の担当者がいる状態です。全員分の入室が必要です。

## 6. 注意
- このアプリは案件管理ではなく、目標意識と日次進捗の共有を目的にしています。
- 大きな誤入力は、マイナス入力で履歴を残して訂正してください。
