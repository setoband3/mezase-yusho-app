# 目指せ優勝！ 管理者向け 月初セットアップ手順

## 月初にやること
1. `設定ページ` を開く
2. 担当者マスタを確認
3. 目標金額を更新
4. 稼働期間（開始日・終了日）を設定
5. 休業日をカレンダーで選択
6. `保存する` を押す
7. ホームに戻って、日次目標が更新されていることを確認

## 担当者マスタ運用
- 新しい担当者は `追加する`
- 使わなくなった担当者は `削除`
- 削除は `active=false` の無効化運用（履歴の整合性を維持）

## 稼働日設定のコツ
- 休業日はカレンダーで複数選択できます。
- 保存後に再度設定ページを開いて、選択内容が保持されているか確認してください。
- 稼働日が0日になると保存できません。

## 入力ロックについて
- ロック判定は `前営業日に全員入室済みか` で決まります。
- ログインした時点で入室ログが記録されます。
- ロック解除のために、未入室者でログインしてから再度ホームへ戻ります。

## トラブル時の初動
1. ページ再読み込み（`Cmd + Shift + R`）
2. 一度 `退出` して再ログイン
3. それでもダメなら管理者が状態確認
   - Supabase: `staff`, `checkins`, `sales`, `goal_settings`

## 変更反映のルール
- コード修正後は GitHub push
- Vercelが自動デプロイ
- 必要に応じて Vercel で `Redeploy`
